    How it works
    • Passwords are created with crypto.getRandomValues() (a secure random source) and rejection sampling, so every character is equally likely.
    • Entropy = length × log2(pool size). Crack time assumes an offline attacker making 10 billion guesses per second.
    • The analyzer checks length, character types, common passwords (including look-alike swaps like p@ssw0rd), keyboard or number sequences, and repeated characters.
    • The SHA-256 hash shows what a system should store instead of the password. Real systems should also add a salt and use a slow algorithm such as bcrypt or Argon2.
