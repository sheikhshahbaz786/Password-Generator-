How it works
  • Random numbers come from crypto.getRandomValues(), a cryptographically secure generator. Math.random() is predictable and is not used.
  • Rejection sampling removes modulo bias, so every character is equally likely.
  • At least one character from each selected type is guaranteed, then the result is shuffled (Fisher-Yates).
  • Entropy = length × log2(character pool size). Crack time assumes an offline attacker making 10 billion guesses per second.
